# LectureLens v1.1.0 — 术语库包 · 深浅主题 · Mac 版准备

Windows 64 位课堂实时字幕翻译工具（免费自用 + 朋友使用）。

## 这个版本带来什么

- **术语库包（8 个内置）**：数学 / 心理学 / 工程 / 医疗 / 计算机 / 人工智能 / 经济 / 法律，每包 116–119 条课程高频术语。术语页一键装到指定课程；包文件就是一个 md 文件，可自己修改，也可以把自己的版本发回当新包分享。
- **深浅主题**：深色（默认，原样）/ 浅色（蓝白 · DeepSeek 风）/ 跟随系统。悬浮字幕条固定深色；偏好按设备永久记住。
- **标签生态**：设置页可自定义「常用标签」（默认仍是 重点/考试/没听懂/待复习）；新增标签管理页——重命名 / 合并 / 删除，只批量改标签行、不碰笔记正文。
- **日常体验 6 项**：
  - 笔记体量徽章（段数/字数，一眼知道这节课多大）
  - 未归档顶栏提醒（近期有课没生成摘要时轻提示，点击直达）
  - 键盘整理流（笔记库内 J/K 移动 · Enter 打开 · Del 删除 · Ctrl+A 全选）
  - 插电提醒（电池供电 + GPU 模型时提示「插电满速」）
  - 一键打包备份（全部笔记 → 一个 zip，保险/换机用）
  - 手机同屏防误触（手机端隐藏会改电脑采集状态的控件；暂停横幅给手机端显示对应文案）
- **Mac 版（Apple Silicon）**：全套适配（mlx-whisper 引擎 / BlackHole 内录 / launchd 自启 / .app 打包脚本 / 《Mac 构建与实测指南》）。**自本版起提供云构建的 arm64 预构建包**——`LectureLens-1.1.0-macos-arm64.zip`（GitHub 的 macOS 云机器实机构建；包内 `--check` 自检全过；ad-hoc 签名、未公证——首次打开需右键 →「打开」，或 `xattr -dr com.apple.quarantine`）。诚实边界：预构建包**尚未经真机全量验收**（mlx 推理 / BlackHole 内录 / 权限弹窗），欢迎尝鲜反馈；自行构建见 `docs/mac-guide.md`。

## 发布前评审的修复（挑用户可见的）

- **主题「重启失忆」双根因修复**：桌面窗口改用持久化存储目录 + 固定优先端口 8787（此前每次随机端口 = 每次都是新"站点"，浏览器存不住任何偏好）。
- **术语库包三处边界**：单个坏文件（如记事本存成 ANSI 的包）只标记该卡为坏包、不再拖垮整个术语页；「重新安装」按钮的确认框如实说明会把块内条目重置为包的译名；安装失败不再留下空术语表 / 课程绑定副作用（先校验后落盘）。
- **卸载目标修正**：一个包装在多门课程时，卸载按钮现在卸载**你当前选中的那门**（判据与动作同源）。
- **浅色主题对比度**：警示色、次要文字、课程色点等在浅色下的对比度按 WCAG 复核并加固。
- **升级验证加固**：覆盖升级后强制**读回安装版本号** + 重跑必装清单（本次 1.0.0→1.1.0 覆盖升级实测 32 项全过：版本读回 1.1.0、关键产物 7/7、四类数据探针原样、--check 退 0）。
- **分发产物纯净**：打包剔除工具态垃圾目录（.mimosa/.zcode），SHA256 可复现。

## 安装 / 升级

1. 下载 `LectureLens-1.1.0-setup.exe`（约 1.41 GB）
2. 双击运行；若弹蓝色「Windows 已保护你的电脑」→「更多信息」→「仍要运行」（未购买代码签名证书，属正常提示）
3. 已装 1.0.0 的**直接覆盖安装**即可：笔记 / 课程 / 术语表 / 设置全部保留（1.0.0→1.1.0 跨版本已实测）
4. **macOS（Apple Silicon / M 系列芯片）**：下载 `LectureLens-1.1.0-macos-arm64.zip`（约 293 MB）→ 解压 → 把 `LectureLens.app` 拖进「应用程序」→ 首次打开对着图标**右键 →「打开」**（未公证，属正常提示）

## 说明

- 卸载默认保留你的笔记（transcripts / config.json / 术语表 / 日志）
- 界面偏好（主题/字号/设置分区记忆）存放在安装目录的 `webview_profile` 子目录
- 随包附「新手指引.txt」；模型缓存默认位于 `C:\Users\<你>\.cache\huggingface\hub`（下载更高档位时占用）
- Mac 用户见仓库 `docs/mac-guide.md`；分发与使用说明见 `docs/distribution-guide.md`
