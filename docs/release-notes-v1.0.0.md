# LectureLens v1.0.0 — 首个可分发版本

Windows 64 位课堂实时字幕翻译工具（免费自用 + 朋友使用）。

## 这个版本带来什么

- **课堂实时双语字幕**：本地 GPU 语音识别（音频不出电脑）+ DeepSeek 翻译，上英下中大字幕
- **手机扫码同屏**：同一 WiFi 下扫码即看，电脑腾出来正常记笔记
- **课后一条龙**：下课一键归档（暂停 → AI 摘要 → 导出），笔记可编辑/打标签/移动课程/回收站
- **模型档位化**：自动检测你的电脑推荐档位（流畅/标准/高/极致），随包自带"标准"档开箱即用，配置好的机器可一键下载更高档位
- **本次改进**：笔记全选套装（全选/反选/批量打标签/批量导出）、课程管理重做、导出按课程自动建子文件夹、设置页五分区（🎙上课/📝笔记/📶连接/🎨外观/⚙系统）

## 安装

1. 下载 `LectureLens-1.0.0-setup.exe`（约 1.41 GB）
2. 双击运行；若弹蓝色「Windows 已保护你的电脑」→ 「更多信息」→「仍要运行」（未购买代码签名证书，属正常提示）
3. 安装为**当前用户**（无需管理员）；首次启动走三步向导（麦克风测试 → DeepSeek key → 试说一句）
4. 想用手机同屏：工具条「📱 手机同屏」→ 打开开关 → 重启一次程序 → 扫码
