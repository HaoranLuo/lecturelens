# 笔记工作流批次（第一批）— 实施依据

> 定稿：2026-10-13（用户确认）。范围：字幕页/笔记库的"选课→整理→归档"闭环 + 手机同屏 + 标签。
> 全部为本地功能，不新增云依赖；红线（免费自用+朋友，不公开分发）不变。
> 开工流程沿用惯例：备份 → 实施 → 门禁（pytest + smoke 真机 + desktop --check）→ 独立评审 → 提交推送。

## 0. 既有地基（实施时直接复用，勿重造）

- 笔记头恒定含课程行：`main.note_header()` + `courses.COURSE_HEADER_PREFIX`（未选课=未分类）。
- **课中切课已自动重标**：`Hub.retag_course`——空笔记重写头；已开记则**追加切换标记**（笔记主归属=开课课程，设计意图是"不让前半段说谎"）。但它只作用于**当前**转录，课后文件不涉及。
- 笔记文件路径白名单：`notes.safe_note_path`（路径穿越防护，重命名/删除必须走同款校验）。
- 导出：`GET /api/notes/export?fmt=md|srt|pdf|docx`，现状=浏览器下载。
- 鉴权：LAN 设备必须带 token；环回豁免；`is_loopback_peer` 已有；`GET /api/config` 已遮蔽 auth_token（故二维码端点必须只允许本机取）。
- 桌面包：pywebview（可用 js_api 提供原生文件夹选择框）；服务端口桌面模式随机、--server-only 固定 8787。
- config 纪律：新增键必须进 `ALLOWED_CONFIG_KEYS` + 取值校验（枚举或专项校验函数）。

## 1. 录制页选课程

- 字幕页工具条加「课程」下拉：列出全部课程 + 「未分类」+ 「新建课程…」（内联输入）。
- 选中 → `POST /api/courses/active`（已有端点）→ 复用 `retag_course` 既有语义（空→改头；记录中→追加标记）；面板/下拉显示当前课程名。
- 与设置页/侧栏的课程选择同源（courses.json active），一处改处处同步（轮询 status.course 或 WS）。

## 2. 课后改归属（归错能改）

- 新端点：`POST /api/notes/course` body `{file, course}` → **正式改写笔记头的课程行**（与课中"追加标记"不同：这是定稿口径，整篇归属改写）。
- 批量：`POST /api/notes/course/batch` body `{files[], course}`。
- UI：笔记行「移动到…」菜单（课程列表+新建）；多选批量移动；完成后列表/侧栏计数刷新。
- 容错：文件不存在/课程不存在 → 400 明确文案；改写失败不改动原文件（先读后整体写回）。

## 3. 导出位置自选 + 文件名

- config 新键 `export_dir`（字符串或 null）：校验=绝对路径、可创建、可写、非系统关键目录；写进白名单+专项校验。
- 设置页「导出」卡：桌面模式调用 **pywebview js_api 原生文件夹选择框**；浏览器/手机模式退化为手动输入路径 + 「打开文件夹」按钮（`os.startfile`）。
- 导出行为：设置后 `导出` 直接落盘，toast「已导出到 …（打开）」；未设置=维持浏览器下载（现状零变化）。
- 文件名：`{课程}_{日期}.{ext}`（课程为空则维持原名）；文件名 sanitize（禁 `\/:*?"<>|` 与保留名）。

## 4. 笔记管理（删除/编辑/重命名/批量）

- 删除=**软删除**：移动到 `transcripts/.trash/`（同盘 rename）；回收站页（笔记库内入口）：恢复 / 彻底删除 / 清空；索引与列表默认排除 .trash。
- 编辑：`PUT /api/notes/{name}` 保存正文（md 原文编辑）；保存后重索引；路径走 `safe_note_path`。
- 重命名：新文件名 sanitize（保留 .md、禁路径分隔/保留名、长度限）；不改内容。
- 批量：多选（行首勾选）→ 批量删除/批量改课程。
- UI 入口：笔记列表行 + 预览页头部（编辑/重命名/删除/移动到）。

## 5. 下课一键归档

- 字幕页工具条「下课」按钮（位置醒目、二次确认可关）：**暂停收音 → 生成摘要（已有 /api/notes/summarize）→ 导出（按 §3 到 export_dir；未设置则下载）→ 汇总 toast**（每步成功/失败逐条列示，单步失败不中断后续）。
- 摘要已在跑/无笔记/无 API key 等边界：明确提示、不空转。

## 6. 可编辑摘要

- 摘要（lecture_*.summary.md）在预览页提供「编辑」→ 保存就地写回（人工修订版）。
- 再次「生成摘要」前检测已有文件 → 确认框「将覆盖你的修改（先备份为 *.summary.bak.md）」→ 覆盖时自动备份。

## 7. 手机扫码同屏

- config 新键 `lan_enabled`（默认 false）。开启 → 服务绑定 0.0.0.0（优先 8787，占用则实际端口），关闭 → 回 127.0.0.1。桌面窗口不受影响（走 127.0.0.1）。
- 新端点 `GET /api/lan-qr`：**仅 loopback 可访问**（含 token，防 LAN 侧读取）；返回 `{enabled, url, svg}`；url=`http://<LAN-IP>:<port>/#t=<token>`；LAN-IP 用 UDP 连接探测主网卡地址。
- 依赖：`qrcode`（MIT，纯 Python 生成 SVG，无需 Pillow）。
- 前端：字幕页「📱 手机同屏」面板——二维码 + URL + 「已连接 N 台设备」（status 增 `ws_clients`，Hub.clients 计数）+ 防火墙三步排查（弹窗点允许/专用网络/同一 WiFi）+ 开关（与设置页同键）。
- 手机端：页面加载时读 `location.hash` 的 `#t=` → 存 localStorage（键沿用现有 token 键名，实施时核对）→ 清 hash；此后免输。
- 隐私透明页补一条：LAN 模式开启时字幕以明文 HTTP 提供给同网段持 token 设备（已有文案基础上补"扫码配对"说明）。
- 边界如实声明：必须同一 WiFi；不做公网映射；二维码勿外传截图（含 token）；token 可随时重置。

## 8. 标签（加入第一批）

- **存储**：笔记文件内的头块一行：`> 标签：#重点 #考试`（与课程行相邻；`notes.note_tags()` 解析——容错：行缺失显示空、未知格式忽略）。存文件不存 sidecar：可移植、随编辑/移动/重命名存活、git 友好。
- **规则**：每个标签 ≤16 字符；禁空格/全角空格/`#`/换行；每篇 ≤20 个；解析时 `#` 起始、空白分隔；同名去重。
- **API**：`POST /api/notes/tags` body `{file, tags:[...]}`（全量替换，幂等）；`/api/notes` 索引每条返回 `tags`；另返回全局标签清单+计数（筛选栏用）。
- **UI 三入口**：
  a) 笔记编辑面板：标签 chips（预设一键：重点/考试/没听懂/待复习）+ 自定义输入；
  b) 笔记库筛选栏：按标签过滤（与课程筛选、全文搜索叠加；搜索命中标签名）；
  c) **上课场景**：字幕页「🏷」按钮 → 一键把预设标签加到**当前笔记**（"没听懂"当场标记）。
- 与 §2/§4 互不冲突：移动到不改标签；重命名/编辑不丢标签（编辑即文件原文，标签行自然保留）。
