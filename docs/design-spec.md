# LectureLens 设计规范 v1（Design Spec）

> 目标：把"网页工具"升级为"有品牌感的桌面软件"。参考体系：Radix Colors（色彩分级）、
> shadcn/ui（语义令牌）、Apple Live Captions（沉浸字幕）、Linear/Raycast（暗色工作台气质）。
> 配套样例：`lecturelens-design-preview.html`（本规范的视觉呈现）。

## 一、设计原则（4 条，冲突时按序裁决）

1. **沉浸优先**——上课态里界面必须消失，只剩字幕；任何装饰不得与字幕争夺注意力。
2. **金色是唯一品牌色**——`#FFD97A` 只用于：中文译文、选中态、主按钮、品牌标识。绝不大面积铺底。
3. **动效克制**——全应用只有 3 个动效（见 §5），其余变化一律瞬时完成。
4. **语义令牌**——颜色/字号/圆角一律走 CSS 变量（命名表见 §2），组件代码里禁止写死色值。改主题=改变量，不动组件。

## 二、色彩系统（语义令牌）

基础背景沿用现有蓝黑调（slate 系），工作台与上课态共享同一套变量。

### 深浅层次（低→高）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0B0E13` | 应用最底层背景 |
| `--surface` | `#12161D` | 卡片/面板/工具条 |
| `--surface-2` | `#171C24` | 悬浮层、输入框、次级面板 |
| `--border` | `#232B35` | 描边、分隔线（1px） |
| `--border-strong` | `#2E3844` | 悬停态描边 |

### 文字层次（对比度均 ≥ 4.5:1）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--text-1` | `#E8EEF5` | 主文字、英文原文 |
| `--text-2` | `#93A1B0` | 次级说明、时间戳 |
| `--text-3` | `#5C6B7A` | 占位、禁用 |
| `--gold` | `#FFD97A` | 中文译文、品牌强调 |
| `--gold-dim` | `rgba(255,217,122,.14)` | 金色的柔和底（选中态背景） |
| `--ok` | `#5FD08A` | 健康/在线 |
| `--warn` | `#E8B44A` | 积压/降级警示 |
| `--err` | `#FF6B6B` | 错误、危险操作 |
| `--partial` | `#7C8B99` | 流式草稿字幕（斜体） |

## 三、字体系统

栈：`"Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif`；时间戳/数字用 `"Consolas", monospace`。

| 令牌 | 字号/行高 | 字重 | 颜色 | 用途 |
|---|---|---|---|---|
| `--cap-zh` | 34px / 1.5 | 600 | gold | 中文译文（上课态主角） |
| `--cap-en` | 24px / 1.45 | 400 | text-1 | 英文原文 |
| `--cap-partial` | 24px / 1.45 | 400 italic | partial | 流式草稿 |
| `--ui-title` | 16px / 1.4 | 600 | text-1 | 工作台页标题、卡片标题 |
| `--ui-body` | 14px / 1.5 | 400 | text-1/2 | 正文、列表项 |
| `--ui-small` | 12px / 1.4 | 400 | text-2 | 时间戳、徽章、辅助说明（最小 11px） |

规则：字幕区每行 ≤ 28 个汉字自动换行；正文区行长 ≤ 72 字符。

## 四、几何系统

- **间距**：8px 网格（4/8/12/16/24/32/48），卡片内边距 16px，区块间距 24px。
- **圆角**：`--radius: 12px`（卡片）→ 按钮/输入 8px → 徽章/药丸 999px（shadcn 式单一基准推导）。
- **描边**：一律 1px `--border`，无投影或仅 `0 1px 2px rgba(0,0,0,.4)`；禁用多层阴影。
- **尺寸**：按钮高 32px（工具条紧凑档 28px）；字幕区安全边距左右 ≥ 24px、内容最大宽 900px 居中。

## 五、动效（全应用仅此 3 个）

| 动效 | 参数 | 场景 |
|---|---|---|
| 淡入 | opacity 0→1，250ms ease-out | 新字幕条目、partial 草稿 |
| 落定 | color/字重过渡 200ms | partial→final 转正 |
| 浮现 | opacity+translateY(4px→0)，200ms | 工具条（鼠标靠近显示/3s 离开隐藏）、回到最新按钮 |

一律尊重 `prefers-reduced-motion`；除此之外没有任何动画（加载进度条的条纹滚动属于状态指示，不算装饰动效）。

## 六、组件规范

- **按钮三档**：主要（gold 底 + #1A1408 字，仅每视图一个）、次要（surface-2 底 + 1px border）、幽灵（无边框，悬停显 surface-2）。
- **徽章（chip）**：`--surface-2` 底 + `--text-2` 字 + 999 圆角；警示态换 warn/err 底 14% 透明度。
- **卡片**：`--surface` 底 + 1px border + radius 12；卡片内不嵌卡片。
- **输入/下拉**：`--surface-2` 底 + 1px border，聚焦时 border 变 gold 50% 透明度。
- **图标**：Lucide 线性风格，16px（工具条 18px），一律 `currentColor`。
- **状态灯**：8px 圆点 + 同色 8% 光晕（在线绿/暂停黄/错误红）。

## 七、页面布局

### 1. 上课态（Immersive）
全屏 `--bg`。顶部工具条默认隐藏（§5 浮现动效唤出）：品牌名 + 状态徽章 + 暂停/模型/字号/导出/清屏/全屏。字幕流居中 900px：时间戳小字 → 英文 → 中文金色。流式草稿斜体灰、尾部"…"。底部一条：mic 状态 + 电平条 + 延迟 ≈Ns + SEGMENTS。离底 >80px 时右下浮现"回到最新"。

### 2. 工作台 · 笔记库
左侧栏 240px（品牌标 + 课程列表 + 设置入口），主区顶部搜索 + 学期筛选，笔记列表行：日期 | 课程徽章 | 首句摘要 | 状态徽章（摘要✓/卡组✓）。点行 → 右侧双栏预览（EN|ZH 对照），顶部操作：摘要/卡组/导出。

### 3. 工作台 · 设置
分区卡片：识别模型（当前卡 + 可下载模型列表带进度条）、音源（麦克风/系统声音）、语言、流式开关、外观、安全（token 掩码 + 重新生成）、API Key（掩码）。全部写回 config.json 白名单。

## 九、落地映射（改 index.html 时）

现 `:root` 变量逐一替换为本规范令牌（`--bg/--en/--zh/--muted/--ok` → `--bg/--text-1/--gold/--text-2/--ok`），工具条/卡片/按钮按 §6 重写；工作台为新增页面，复用同一套令牌。分两步上线：先上课态换肤（风险低），再增工作台。
