# LectureLens v1.1.1 — 首期反馈修复

Windows 64 位 / macOS（Apple Silicon）课堂实时字幕翻译工具。

## 修复了什么（第一期朋友反馈）

1. **连续说话时中文字幕等太久**：分句上限从 15/18 秒下调到 **8/10 秒**——老师一直说时，中文字幕最多约 10 秒内出现（原来要等近 20 秒）。已安装旧版且没手动调过参数的，升级后自动迁移；想调回随时在设置页「高级 · 分句调优」改。
2. **无法中断、想立刻看这句**：工具条新增 **⚡ 断句** 按钮——点一下就把老师正说的这句提前结算并翻译，不用等停顿。
3. **字号范围更宽 + 行距自动适配**：字号 18–44 → **14–56**；在大字号下行距与条目间距自动放大（小窗、投影、大屏都好看）。
4. **导出中文乱码**：SRT 字幕统一写 UTF-8 BOM（Windows 播放器/剪辑软件不再把中文当 GBK 读成乱码）；Word 导出的标题也显式指定中文字体。
5. **退不出悬浮字幕条 / 退不掉后台程序（尤其 Mac）**：托盘退出加了 5 秒兜底（主循环卡住也会强制退出并释放单实例锁）；悬浮条 ✕ 在服务异常时有了备用关闭通道。

## 安装 / 升级

1. **Windows**：下载 `LectureLens-1.1.1-setup.exe`（约 1.41 GB），双击 → 若弹蓝色「Windows 已保护你的电脑」→「更多信息」→「仍要运行」→ 一路下一步
2. **macOS（Apple Silicon）**：下载 `LectureLens-1.1.1-macos-arm64.zip` → 解压 → 把 `LectureLens.app` 拖进「应用程序」→ 首次打开右键 →「打开」
3. **已装旧版的直接覆盖安装即可**：笔记 / 课程 / 术语表 / 设置全部保留（1.0.0→1.1.1、1.1.0→1.1.1 均已实测）
