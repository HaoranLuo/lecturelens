主题 B15 · 本设备

只影响本设备的界面配色；每台设备各记各的（手机扫码同屏时 互不干扰）。
深色 = 原配色（默认，老用户零变化）；浅色 = 白底蓝调； 跟随系统 = 跟着操作系统的「浅色 / 深色」设置走，系统一改界面 立刻跟着变（不用刷新）。
悬浮字幕条始终是深色：它是盖在视频/课件上的浮层，压在白色课件上的白底 字幕条会看不清，深色在任何背景上都清楚。

字幕显示 B2 · 历史行渐隐

上课时把当前句上方的最近几行做渐隐（半透明 + 缩小）， 视线自然落在最新一句上。
只改变这几行的呈现：不删除任何条目，向上回看历史（最多 1000 条）不受 影响；渐隐行不接收鼠标交互（点击/划选会落到字幕背景上），需要复制它们时先 选「不渐隐」。

悬浮字幕条 B1 · 桌面版

第二块屏场景：独立的无边框置顶小窗，只显示最新一句中英字幕， 可拖动到任意位置；主窗最小化时它仍显示。 点击穿透为尽力而为、仅 Windows 支持（Win32 WS_EX_TRANSPARENT）； macOS 及其它平台自动降级为可关闭窗口（浮窗照常显示，只是不穿透）—— 失败时同样降级，不静默假成功；穿透开启后请用托盘菜单「字幕条点击穿透」 解除。

全局快捷键 B12 · 桌面版

全局生效：任何窗口聚焦时都能用，不用先切回本应用。
格式 ctrl+alt+l：修饰键 ctrl/alt/shift/win 至少一个 + 主键一个 （a-z / 0-9 / f1-f12）；大小写与顺序不限（win/meta/super/cmd/command 等价， macOS 上就是 ⌘ 键）。
热键被其它程序占用或权限不足时自动降级为仅托盘菜单操作， 原因见下方状态行；不需要可整个关掉。

导出 §3 · 导出位置

选一个文件夹后，导出（笔记库行 / 预览页的「导出」按钮） 会把产物直接写到那里，不再弹浏览器下载。
文件名统一为 课程_日期.扩展名（如 数学_20261013.pdf；没有课程 归属的笔记维持原名），同名文件不会被覆盖（自动加 -2）。
有课程归属的笔记会按课程分子文件夹（B1）：落点是 导出目录 / 课程名 /（如 机器学习/机器学习_20261013.md）—— 「对应的笔记本」的物理版，Obsidian / 同步盘直接可用；课程名为空或「未分类」 的笔记仍落在你选的目录根下。

备份全部笔记（B10）：把库里全部笔记打成一个 LectureLens备份_日期.zip（换电脑/保险用）——一次一份整库快照， 不受「一次最多 50 篇」的选包上限约束；不含回收站（已删的不进快照）， 也不含 AI 摘要 / 时间轴等派生物（要连摘要一起带走，请在那篇的预览页 单独导出）。

手机连不上？按顺序排查这三步

  1. 防火墙弹窗点「允许访问」：首次开启时 Windows 会问是否允许 LectureLens.exe 联网（开发态直接跑源码时显示为 python.exe）——必须选允许；当时点了「取消」的话，到 「Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙」里把这个程序的 两个勾（专用/公用）补上。
  2. 网络配置选「专用网络」：连着校园网/公司网时，Windows 常把网络判成 「公用」并默认拒绝入站；在「防火墙和网络保护」里把当前网络改成「专用网络」。
  3. 手机与电脑连同一个 WiFi：别一个连 WiFi 一个连热点/有线到别的网段； 扫码前确认面板里显示的是「已开启」（而不是「重启后生效」）。

仅同一 WiFi 可用（不做公网映射，出门在外连不上是正常的）； URL/二维码里带着访问 token——别把截图外传，手机丢了或截图泄了可在设置页 「安全」卡重新生成 token（已配对的旧设备会被立即断开，需用新 token 重连）。
