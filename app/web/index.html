字幕显示 B2 · 历史行渐隐

上课时把当前句上方的最近几行做渐隐（半透明 + 缩小）， 视线自然落在最新一句上。
只改变这几行的呈现：不删除任何条目，向上回看历史（最多 1000 条）不受 影响；渐隐行不接收鼠标交互（点击/划选会落到字幕背景上），需要复制它们时先 选「不渐隐」。

悬浮字幕条 B1 · 桌面版

第二块屏场景：独立的无边框置顶小窗，只显示最新一句中英字幕， 可拖动到任意位置；主窗最小化时它仍显示。 点击穿透为尽力而为（Win32 WS_EX_TRANSPARENT）——失败自动降级为可关闭窗口； 穿透开启后请用托盘菜单「字幕条点击穿透」解除。

全局快捷键 B12 · 桌面版

全局生效：任何窗口聚焦时都能用，不用先切回本应用。
格式 ctrl+alt+l：修饰键 ctrl/alt/shift/win 至少一个 + 主键一个 （a-z / 0-9 / f1-f12）；大小写与顺序不限（win/meta/super 等价）。
热键被其它程序占用或权限不足时自动降级为仅托盘菜单操作， 原因见下方状态行；不需要可整个关掉。

合规红线

  • 免费自用 + 朋友：不收费、不注册公司、不分发——Student visa 禁 self-employment；商业化决策推迟至毕业后（README.md:3 原文口径）
  • 「不分发」的边界待裁决：若含「朋友装机」则打包/分发相关条目挂起， 若仅指不公开分发则按计划执行（docs/upgrade-plan.md §3.3-1，须本人裁决）
  • 课堂音频仅限本人学习用途，笔记不外传

数据去向

  • 音频不出电脑：采集 / 识别 / 分句全在本机（faster-whisper 本地推理）
  • 文字出网：仅识别后的文本经 HTTPS 发 DeepSeek（翻译 / 摘要 / 卡组）
  • 笔记在本地：transcripts/ 目录，不进 git、不上传
  • LAN 模式会对外提供明文 HTTP：桌面模式只监听 127.0.0.1；用 --server-only 时服务监听 0.0.0.0，同一 WiFi 内持 token 的设备可用 明文 HTTP 读到字幕文本——仅在可信网络启用，详见隐私透明页

详见 隐私透明页（B9 最小版）； 重开首启向导。
