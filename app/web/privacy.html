隐私透明页 —— 数据去向一页说清

LectureLens 课堂实时字幕翻译 · 本页为静态声明，不含任何接口数据

🎙 音频不出电脑

麦克风 / 系统声音的采集、分句、语音识别全部在本机完成（faster-whisper 本地推理）。音频从不离开这台电脑，无上传、无云端转写。

📝 文字发 DeepSeek

只有识别后的英文文本经 HTTPS 发送到 DeepSeek API，用于翻译、课后摘要 与 Anki 卡组生成。请求不携带音频、不携带身份信息；API Key 只存在本机 （环境变量 / .env，不进 git）。

📶 局域网默认关闭 · 扫码配对

默认（桌面模式与 --server-only 一样）只监听 127.0.0.1，字幕不出本机。 在字幕页 / 设置页打开 📱 手机同屏（config lan_enabled）并 重启 LectureLens 后，服务才监听 0.0.0.0：同一 WiFi 内 持 token 的设备可以读到字幕文本（识别原文 + 中文译文），供手机当第二块屏。
扫码配对：手机同屏面板里的二维码就是访问地址 （http://<电脑IP>:8787/#t=<token>，token 放在地址的 # 片段里——浏览器不会把片段发给服务端，手机页面读到后存本地、随即把地址栏 里的片段抹掉，此后免输）。二维码/地址等于凭据，别外传截图；手机丢了或截图 泄了，在设置页「安全」卡重新生成 token：已在线的旧设备会被立即断开， 此后必须用新 token 才能重连（刷新页面也过不去）。
两点须知：① 传输是明文 HTTP（无 TLS）——同一网段的被动监听者理论上能看到 内容，故只在可信网络里开；② token 是唯一门禁，首启已打印、设置页「安全」卡可重新 生成；关掉 LAN 鉴权则同 WiFi 任何人都能看字幕。嫌风险就别开手机同屏。

💾 笔记在本地

双语课堂笔记、摘要、卡组全部写在程序目录的 transcripts/ 下， 不进 git、不上传；日志在 logs/（API key 经脱敏过滤不落盘）。
