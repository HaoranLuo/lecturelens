隐私透明页 —— 数据去向一页说清

LectureLens 课堂实时字幕翻译 · 本页为静态声明，不含任何接口数据

🎙 音频不出电脑

麦克风 / 系统声音的采集、分句、语音识别全部在本机完成（faster-whisper 本地推理）。音频从不离开这台电脑，无上传、无云端转写。

📝 文字发 DeepSeek

只有识别后的英文文本经 HTTPS 发送到 DeepSeek API，用于翻译、课后摘要 与 Anki 卡组生成。请求不携带音频、不携带身份信息；API Key 只存在本机 （环境变量 / .env，不进 git）。

📶 局域网仅 --server-only 模式

默认的桌面模式只监听 127.0.0.1，字幕不出本机。用 --server-only 开 LAN 模式时服务监听 0.0.0.0：同一 WiFi 内持 token 的设备可以 读到字幕文本（识别原文 + 中文译文），供手机当第二块屏。
两点须知：① 传输是明文 HTTP（无 TLS）——同一网段的被动监听者理论上能看到 内容，故只在可信网络里开；② token 是唯一门禁，首启已打印、设置页「安全」卡可重新 生成；关掉 LAN 鉴权则同 WiFi 任何人都能看字幕。嫌风险就别开 LAN 模式。

💾 笔记在本地

双语课堂笔记、摘要、卡组全部写在程序目录的 transcripts/ 下， 不进 git、不上传；日志在 logs/（API key 经脱敏过滤不落盘）。
